## Organization by Career Stage

Each region folder contains grants organized by audience:
- **Faculty / PI** - Tenure-track and independent researchers
- **Postdocs / ECRs** - Postdocs and early career researchers
- **Students / PhD** - Graduate students and PhD candidates
- **OSS Maintainers** - Open source software developers
- **Indie Builders** - Independent researchers and microgrant seekers
