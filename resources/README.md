# Resources

This directory contains raw research source material used when compiling the
curated grant list in this repository.

- `research-notes-academic-funding.md` — machine-generated research export:
  "Awesome Grants: Comprehensive Academic Funding Opportunities"
- `research-notes-funding-guide.md` — machine-generated research export:
  "Comprehensive Funding Guide for Academic Researchers and Builders"

These files are not part of the published site (the directory is excluded from
the Jekyll build in `_config.yml`) and are retained only for provenance.
Information in them may be outdated; the curated `README.md` and the pages
under `docs/` take precedence.
